# 合作商积分规则

> 适用范围：合作商终端（/partner）与 管理后台（合作商 → 合作商积分）共享同一套积分体系；
> 计算实现：`src/stores/scoreStore.ts`（六维派生计算器 `computeScore`），规则配置：`src/stores/referralStore.ts`（推介奖励规则）。
> 本文档总结截至 2026-11 的全部积分规则，页面上的「积分规则」表（两端一致）由 `buildScoreRules()` 动态生成。

## 一、总分构成

```
积分总分 = 期初分 + 基础积分 + 经营积分 + 报备积分 + 推介积分 + 申报积分 − 扣分规则
```

- **期初分**：合作商基础分快照（`data/partnerScores.ts` scoreBases，如云茶 62 分、履约率 90%），审批通过时赋予。
- **六维**中「基础 / 经营 / 报备 / 推介」为**派生维度**（实时按订单、报备、推介数据计算，不写台账）；
  「申报 / 扣分规则」为**台账维度**（事件发生时写入积分台账流水，流水在两端积分台账 Tab 均可查）。
- **比单评分**取「经营 + 报备 + 推介 + 申报 − 扣分规则」等动态合计参与定标（按商品积分优先）。

## 二、六维明细

### 1. 基础积分（派生，封顶 14 分）

| 事项 | 分值 |
|---|---|
| 合作商注册审批成功 | +1 |
| 每维护 1 个门店信息 | +0.5（封顶 5 分） |
| 每 1 个主营品牌 | +0.5（封顶 3 分） |
| 每报价 1 个商品（供货报价覆盖） | +0.1（封顶 5 分） |

### 2. 经营积分（派生，不封顶）

| 事项 | 分值 |
|---|---|
| 每成功接单且履约至**结算完成**的订单 | +0.2 |
| 经营结算总金额每 1 万 | +0.2 |

### 3. 报备积分（派生，不封顶）

| 事项 | 分值 |
|---|---|
| **订单报备**审批通过 | +0.1 / 条 |
| **订单报备**转入该合作商名下并接单（含后续履约各态） | +0.1 / 单 |
| **商品报备 / 地区报备**报备成功本身 | 不加分 |
| 基于商品 / 地区报备转入的订单，按**结算金额每 1 万** | 额外 +0.1（在经营积分正常加分之外） |

> 说明：报备转出的有效依据 = 订单报备命中列表的首个匹配（按 订单报备 > 商品报备 > 地区报备 优先级）；
> 无货源订单报备确认后退回分发待处理，不产生报备积分。

### 4. 推介积分（派生，不封顶）

| 事项 | 默认分值 |
|---|---|
| 茶培训推介成功 | +1 |
| 茶活动推介成功 | +1 |
| 入驻淡茶（推荐新合作商注册入驻）成功 | +3 |

- 推介成功的两个来源：
  1. 合作商在「业务推介」发起 → 管理后台推介管理推进至「推介成功」；
  2. **入驻淡茶推荐归因**：新合作商通过合作商的专属注册链接 / 二维码（`/partner/register?ref=<合作商ID>`）完成注册，
     自动为推荐人生成 1 条「推介成功」的入驻淡茶记录并按规则加分。
- **积分奖励可在管理后台「合作商 → 推介管理 → 推介奖励规则设置」按业务调整**（同时可配置分润奖励与其他奖励）；
  积分计算与两端「积分规则」表实时使用最新配置。

### 5. 申报积分（台账，评估给分）

- 合作商在「积分管理 → 积分申报」主动发起申报，类型：**客户拜访 / 活动组织 / 其他**
  （入驻推介不在申报类型中，其积分由「业务推介 · 入驻淡茶」推介成功自动计入）。
- 填写申报标题 + 事项描述（必填），可上传**凭证图片（非必输，最多 5 张）**。
- 管理后台「合作商积分 → 申报积分评估」：待评估 → 评估弹窗填写评估分值（>0）与评估意见 → **通过并入账 / 驳回**；
  通过后自动写入积分台账（原因含申报类型前缀）。
- 申报进展在合作商端「申报管理」Tab 以三步条展示：已提交 → 评估中 → 已出结果（通过 +N 分 / 已驳回）。

### 6. 扣分规则（台账人工 + 派生自动，不封顶）

| 事项 | 分值 |
|---|---|
| 客户投诉 / 违规行为（管理后台「处罚登记」人工登记，原因必填） | 按情节扣分（负值） |
| **发货延迟自动扣分**：接单后第 4 天起每延迟 1 天发货 | −0.1 / 天 |

- 发货延迟细则：**接单当天、第 2 天、第 3 天发货都不扣分；第 4 天开始每天扣 0.1 分**（延迟 3 天起扣，`max(0, 延迟天数−2) × 0.1`）；
  已接单未发货的订单按接单日期累计扣至当日；发货 / 结算后按实际发货日期定格。
- 台账维度展示名统一为「扣分规则」（六维汇总中区分人工与延迟扣分明细）。

## 三、积分载体与页面

| 页面 | 内容 |
|---|---|
| 合作商终端 · 积分管理 | 六维统计卡、积分总分条（期初分 + 六维合计 + 履约率）、积分规则表、积分申报弹窗（800px，三类型一行）、申报管理（进展三步条）、积分台账（分页流水） |
| 管理后台 · 合作商积分 | 积分规则表（动态）、申报积分评估（待评估 / 已处理 + 评估弹窗：申报事项 + 凭证图 + 评估给分 / 驳回）、积分构成榜（总分 + 六列 + 履约率）、台账抽屉（六维汇总 / 台账流水 / 处罚登记与手动调分） |
| 管理后台 · 推介管理 | 业务推介单跟进 + 入驻淡茶归因记录 + **推介奖励规则设置**（积分奖励 / 分润奖励：固定金额或成交金额百分比二选一 / 其他奖励），配置展示在合作商「新增业务推介」弹窗 |
| 比单定标 | 报价分 + 积分分（按上述动态合计）加权定标 |
