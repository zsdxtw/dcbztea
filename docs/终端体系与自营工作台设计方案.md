# 终端体系定义与自营工作台设计方案

> 基于 2026-11 项目现状：管理后台（9 模块）、合作商终端、客户终端三端并存，但终端名称未统一显式定义；
> 自营链路（销售单分发·转自营 → 接单 → 采购&发货 → 运输 → 妥投 → 确认收货）已于 2026-11-01 在管理后台「销售 → 销售单自营」落地。
> 本方案：① 显式定义四端体系与命名；② 新增第四端「自营工作台」，承载自营执行（接单/发货/采购/结算），与管理后台共用同一数据层。

---

## 一、终端体系定义（4 端）

| # | 终端全称 | 简称 | 路由前缀 | 登录入口 | 使用者 | 布局风格 |
|---|---------|------|---------|---------|--------|---------|
| 1 | **淡茶半盏管理后台** | 管理后台 | `/` | 免登（演示） | 平台运营/管理岗 | 顶栏 9 模块 + 侧边多级菜单（现有 AppLayout） |
| 2 | **合作商工作台** | 合作商工作台 | `/partner` | `/partner/login`（合作商账号） | 合作商（供应商） | 简约侧边栏：品牌 + 菜单 + 合作商信息 + 用户（现有 PartnerLayout） |
| 3 | **客户采买平台** | 客户采买平台 | `/customer` | `/customer/login` | 客户采购人员 | 简约侧边栏，商城风（现有 CustomerLayout） |
| 4 | **自营工作台**（新增） | 自营工作台 | `/selfop` | `/selfop/login`（自营运营账号） | 自营运营 / 跟单人 | 参照合作商工作台：简约侧边栏 + 品牌副题「自营工作台」 |

### 1.1 命名统一落地

- 新增 `src/data/terminals.ts`：四端常量（key / 全称 / 简称 / 路由前缀 / 登录路径 / 图标 / 主题色模块），全站统一引用，避免散落硬编码。
- **管理后台 TopNav** 终端切换区改为三按钮：`合作商工作台` `自营工作台` `客户采买平台`（原「合作商终端/客户终端」更名并新增自营入口）。
- 各端 Layout 品牌区副标题统一为终端全称：管理后台无副题（主站）、`淡茶半盏 · 合作商工作台`、`淡茶半盏 · 客户采买平台`、`淡茶半盏 · 自营工作台`；登录页标题同步。
- `document.title` 随端切换：`淡茶半盏 — 管理后台/合作商工作台/客户采买平台/自营工作台`。
- 主题：合作商端沿用翡翠绿（product 模块色）；自营工作台用销售模块色（茶金）以区分身份。

### 1.2 数据与权限边界

| 终端 | 可见数据 |
|------|---------|
| 管理后台 | 全部（分发/比单/采购/库存/财务…，全局视角） |
| 合作商工作台 | 本合作商名下订单（partnerId 匹配）、自己的报备/报价/抢单/结算 |
| 客户采买平台 | 本客户的商品浏览/购物车/订单 |
| 自营工作台 | `path === 'self'` 的销售单 + `source === 'self'` 的采购单（不接触转派单与合作商数据） |

## 二、自营工作台设计

### 2.1 定位与原则

- **定位**：自营销售单的**执行端**——管理后台「销售单分发」把订单转入自营后，后续接单、拆单、采购、发货、物流、结算全部在此完成。
- **单一事实源**：与管理后台共用 `orderFlowStore` / `purchaseStore`（zustand 全局单例），自营工作台的接单/发货实时反映到管理后台「销售单自营/销售单列表」，反之亦然。
- **复用而非复制**：将管理后台「销售单自营」页的详情抽屉（接单/退回/拆单/采购&发货/物流/确认收货）抽取为共享组件 `src/components/selfop/SelfOrderDetail.tsx` 等，两端共用同一交互；管理后台菜单**暂时保留**（后续可降级为只读监控或移除）。
- **登录态**：参照合作商终端 localStorage 方案（`selfopAuth`），演示登录页选择「自营运营人员」身份（跟单人 persona），接单时默认带出当前登录人为跟单人。

### 2.2 菜单规划（5 项一级菜单）

```
自营工作台
├─ 工作台        /selfop/dashboard   概览与待办
├─ 订单          /selfop/orders      自营订单执行（核心）
│   ├─ 订单管理  /selfop/orders                待接单→确认收货全链路处理
│   └─ 物流跟踪  /selfop/logistics              包裹维度跟踪（自营分仓+采购直发）
├─ 采购          /selfop/purchase    以销定采采购单处理
├─ 结算          /selfop/settlement  自营订单与采购单结算
└─ 设置          /selfop/account     账号信息（运营人员 persona）
```

### 2.3 功能设计明细

#### ① 工作台 `/selfop/dashboard`
- 统计卡：待接单 / 已接单（含采购在途·到货待发）/ 已发货运输中 / 妥投待确认 / 本月自营销售额。
- 待办清单（点击直达）：N 单待接单、N 单到货待出库、N 单全部妥投待确认收货。
- 最近自营订单表（编号/客户/金额/状态/跟单人）。

#### ② 订单管理 `/selfop/orders`（= 管理后台「销售单自营」整体迁移）
- 状态 Tab：全部 / 待接单 / 已接单 / 已发货运输中 / 妥投 / 确认收货。
- 列表：订单编号（母子标注）/ 客户 / 商品 / 金额 / 跟单人 / 采购单 / 状态 / 物流包裹统计 / 操作（查看）。
- 详情抽屉（共享组件，按状态给操作，**仅详情页操作**口径与管理后台一致）：
  - 待接单：接单（填跟单人，默认当前登录运营）、退回（回分发·待处理，标注「自营退回」）；
  - 已接单：拆单（子单继承自营，母子进销售单列表）、**采购&发货**（分仓直发：各仓数量+独立快递单号；缺口以销定采：供应商+直发/入库制+可多采）、到货入库 / 到货出库；
  - 运输中：包裹级「模拟妥投」推进（系统跟踪物流的演示替代）；
  - 妥投：确认收货（人工/联机，联动采购单结算）。
- 进入自营后订单内容**不可修改**。

#### ③ 物流跟踪 `/selfop/logistics`
- 汇聚两类包裹：自营分仓包裹（SelfShipment）+ 以销定采直发包裹（PO packages，source=self）。
- 列表：包裹号 / 关联订单 / 仓库或供应商 / 商品 / 快递公司单号 / 状态（运输中/已妥投）/ 时间；按单号、订单号检索。
- 行操作：模拟妥投（推进物流，全部妥投自动把订单推入「妥投」）。

#### ④ 采购 `/selfop/purchase`
- 以销定采采购单列表（`source === 'self'`）：采购单号 / 关联销售订单（母子单号）/ 供应商 / 模式（直发客户/入库制）/ 金额 / 状态 / 包裹。
- 操作：入库制到货入库 → 已入库；出入库出库（回订单「到货出库发货」）；直发模式由供应商端发货（本端跟踪）；按单结算。
- 采购视角与管理后台「采购 → 采购订单 · 分发采购」同源（PO 实体），仅过滤自营来源。

#### ⑤ 结算 `/selfop/settlement`
- 待结算：已确认收货（completed）自营订单的结算台账（订单金额 / 采购成本 / 毛利估算 = 金额 − 采购金额）。
- 已结算：采购单 settled 的记录。
- 操作：按单发起结算（联动 `settleByChild`，与管理后台采购对账一致）。

#### ⑥ 设置 `/selfop/account`
- 当前运营人员（persona：姓名/角色/负责跟单订单数）、切换身份（演示）、退出登录。

### 2.4 路由与文件规划

```
src/pages/selfop/
├─ SelfopLayout.tsx      布局（参照 PartnerLayout：品牌+菜单+用户，销售主题色）
├─ SelfopLogin.tsx       登录（选择/输入自营运营账号，localStorage selfopAuth）
├─ SelfopDashboard.tsx   工作台
├─ SelfopOrders.tsx      订单管理（复用共享详情抽屉）
├─ SelfopLogistics.tsx   物流跟踪
├─ SelfopPurchase.tsx    采购
├─ SelfopSettlement.tsx  结算
└─ SelfopAccount.tsx     设置
src/components/selfop/   共享业务组件（详情抽屉、采购&发货弹窗等，从 sales/OrderShipping 抽取）
router.tsx               新增 /selfop/* 路由组
src/data/terminals.ts    四端常量
```

### 2.5 与现有功能的关系

| 现有功能 | 处理 |
|---------|------|
| 管理后台 销售 → 销售单自营 | **暂时保留**：逻辑抽为共享组件后两端共用；二期可降级为只读监控（看进度不做操作）或移除 |
| 管理后台 销售 → 销售单分发 | 不变：转自营入口在分发，转出后引导「前往自营工作台」 |
| 管理后台 采购 → 采购订单/采购需求 | 不变：全局采购视角；自营工作台采购菜单是其「自营来源」子视角 |
| 合作商工作台 | 不变（更名按钮文案） |

## 三、实施路线（三步，可独立交付）

1. **终端定义与更名**：terminals.ts + TopNav 三按钮 + 两端 Layout 副标题/登录页/标题更名 —— 纯文案与常量，风险低。
2. **自营工作台骨架**：Layout/Login/Dashboard + 路由 + 主题 + 登录态 persona。
3. **功能迁移**：详情抽屉与弹窗组件化抽取 → 订单管理/物流/采购/结算四页；管理后台销售单自营改为引用共享组件（保留菜单）。
