# 状态显示名对照表（四维状态 · 三端）

> 依据：提交 `ae9f7c1` 的当前代码逐点核实。
> 口径来源：`EXTERNAL_STATUS_LABELS`（data/externalOrders.ts）、`FULFILLMENT_STAGE_LABELS`（utils/fulfillment.ts）、`PARTNER_ORDER_STATUS_LABELS`（data/partner.ts）、`STAGE_META`（components/selfop/selfStage.ts）、`PartnerOrders.STATUS_TABS`、`fulfillStateOf / settleStateOf / invoiceStateOf / familyStatesOf`（utils/salesOrderFamily.ts）。
> 三端：淡茶半盏管理后台 / 合作商工作台 / 自营工作台。

## 一、分发状态（`processStatus` · 仅淡茶半盏后台展示）

| 枚举值 | 定义 | 后台·列表/详情显示名 | 后台·分发页流程图 |
|---|---|---|---|
| `pending` | 新单初始态，等待选择分发路径 | **待分发** | 待分发 |
| `report_match_pending` | 保存时命中报备，待人工确认后转报备合作商 | **报备-匹配待确认** | 报备-匹配待确认 |
| `self_pending` | 已转自营路径，等自营工作台接单 | **自营待接单** | 自营待接单 |
| `comparing` | 比单公开报名中（限时） | **分发比单中** | 分发比单中 |
| `distribute_pending` | 已转出合作商，等终端接单 | **转派待接单** | 转派待接单 |
| `processed` | 履约状态进入已接单及后续时自动置入（patchOrder 收口） | **分发已完成** | 分发已完成 |
| `cancelled` | 订单取消（贯穿态） | **已取消** | 已取消 |

> 合作商工作台 / 自营工作台**不展示分发状态**——终端视角只关心自己名下的履约。

## 二、履约状态（`fulfillment.stage` · 三端共用，显示名有差异）

| 枚举值 | 定义 | 淡茶后台（列表/详情·包裹细档） | 合作商工作台·行内药丸 | 合作商工作台·TAB | 自营工作台（`STAGE_META`） |
|---|---|---|---|---|---|
| `pending_accept` | 已分发，待主体接单 | 待接单 | 待接单（比单报名中加显「比单中」双药丸） | 待接单 | 待接单 |
| `accepted` | 主体已接单 | 已接单 | 已接单 | 已接单 | 已接单 |
| `shipping` | 有物流单号，在途（已发货档） | 运输中 | 运输中 | **已发货**（TAB=运输中+妥投合并桶） | 已发货（TAB）/ 运输中（行内） |
| `transit` | 物流投递完成（已发货档） | 妥投（部分时显**部分妥投**） | 妥投 | 已发货（同上桶） | 已发货（TAB）/ 妥投（行内） |
| `confirmed` | 客户确认收货（管理后台手工/联机） | 全部已确收（部分时显**部分已确收**） | 已确收 | 已确收 | 已确收 |
| `cancelled` | 取消贯穿 | 已取消 | 已取消 | 已取消 | 已取消 |

> 自营工作台 TAB 与合作商工作台同构：全部 / 待接单 / 已接单 / 已发货（运输中+妥投合并桶）/ 已确收 / 已取消；行内显示细档。

后台独有的**细档药丸**（`fulfillStateOf`，按履约单发货单包裹推导）：

| 细档 | 判定 |
|---|---|
| 未履约 | 分发状态 ∈ 待分发/报备-匹配待确认/分发比单中（尚未进入履约主体） |
| 待接单 | 分发状态 ∈ 自营待接单/转派待接单 |
| 已接单 | 分发已完成且无发货包裹 |
| 部分已发货 | 部分包裹已发货（shipped），其余未发 |
| 运输中 | 全部包裹 shipped、无妥投 |
| 部分妥投 | 部分包裹妥投、其余在途 |
| 妥投 | 全部包裹妥投、无已确收 |
| 部分已确收 | 部分包裹已确收 |
| 全部已确收 | 全部包裹已确收（履约完成判定） |

包裹（发货单）状态链：`shipped` 运输中 → `delivered` 妥投 → `confirmed` 已确收。

## 三、结算状态（按发货单 `settled` 标记派生）

| 档位 | 定义 | 淡茶后台 | 合作商工作台 | 自营工作台 |
|---|---|---|---|---|
| 履约单维度 | 未结算 / 部分结算 / 已结算（分母=已妥投/已确收发货单；无已妥投包裹回退订单级 `settled`） | **未结算 / 部分结算 / 已结算** 药丸 | —（不在订单列表展示，见下） | — |
| 母单聚合 | 全部未结算→未结算；有部分结算→结算中；部分履约单已结算→部分已完成；全部→全部已完成 | **未结算 / 结算中 / 部分已完成 / 全部已完成** + x/y | — | — |
| 终端行内 | 订单级 `settled` 标记 + `settleOnTime` | — | **已结算 · 按时 +5 分** / **已结算 · 超时 -5 分** / **待结算** / 履约中；TAB「已结算」按订单级 settled 过滤 | 结算台账行内 **已结算 / 待结算** |

结算操作入口：后台分发页抽屉「结算（按时/超时）」+ 财务合作商结算页（支持按发货单部分结算）。`settleOnTime` 为纯质量标记（按时/超时），不承担"是否已结算"语义。

## 四、开票状态（`invoiceStatus` · 仅淡茶半盏后台）

| 枚举值 | 定义 | 后台显示名 |
|---|---|---|
| `uninvoiced`（缺省） | 未登记开票 | **未开票** |
| `partial` | 部分开票（手工登记） | **部分开票** |
| `invoiced` | 全额开票 | **已开票** |
| 母单聚合 | 未开票 / 开票中（有部分开票）/ 部分已完成 / 全部已完成 + x/y | **未开票 / 开票中 / 部分已完成 / 全部已完成** |

前置条件：仅**已确收**订单可登记（预开票待业务确认）；合作商/自营终端不展示开票维度。

---

## 五、贯穿与联动

- **已取消**：三端均显示「已取消」（红药丸）；取消后分发与履约状态同时变为已取消，x/y 聚合分母剔除取消单（active 口径）。取消逆向：比单中清 compare 会话；在途包裹写入轨迹提示召回；拆分家族母单禁止直接取消。
- **已驳回**（`rejected`）：仅合作商终端 TAB 存在，当前无写入链路（死枚举，评审 P9 待业务确认）。
- **比单中双药丸**：合作商终端待接单且已报名的订单显示「待接单 + 比单中」双药丸；详情显示「待接单-比单中」。
