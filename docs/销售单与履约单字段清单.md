# 销售单与履约单 · 字段清单

> 数据模型：`src/types/index.ts` 的 `ExternalOrder`（销售单与履约单共用同一接口，**履约单 = parentCode 指向母销售单编号的子单**）。
> 生成规则：手工录入 / 直连推送进入管理后台时，默认生成履约单01（履约单号 = 母销售单号 + `LY01`）；拆单后拆出部分生成履约单02…（编号 = 母销售单号 + `LY02` 起）。
> 展示层：`src/utils/salesOrderFamily.ts` 的 `fulfillmentUnitsOf` 推导履约单单元（未拆分 = 默认履约单01 虚拟挂母单；拆分后 = 真实子履约单）。

### 5. 分发状态枚举（ExternalProcessStatus · 履约单 5 态 + 未分发/已取消）

| 状态 | 名称 | 说明 |
|---|---|---|
| `unprocessed` | 未分发 | 销售单刚进入平台、尚未送分发（订单状态＝未处理，不生成履约单） |
| `pending` | 待分发 | 已生成履约单，等待选择分发路径 |
| `self_pending` | 自营待接单 | 转自营路径（履约状态一般为待接单） |
| `comparing` | 分发比单中 | 按商品公开报名（限时） |
| `distribute_pending` | 转派待接单 | 已转出合作商，等终端接单（履约状态一般为待接单） |
| `processed` | 分发已完成 | 履约状态进入已接单及后续时自动置为本状态 |
| `cancelled` | 已取消（存储值） | 不再展示为分发状态——已取消只体现在「订单进度」 |

### 6. 履约状态枚举（FulfillmentStage · `fulfillment.stage`）

| 状态 | 名称 | 说明 |
|---|---|---|
| `pending_accept` | 待接单 | 已分发待主体接单 |
| `accepted` | 已接单 | 履约主体接单 |
| `shipping` | 运输中 | 有物流单号（已发货档） |
| `transit` | 已妥投 | 物流投递完成 |
| `confirmed` | 已确收 | 客户确认收货（管理后台手工/联机操作） |
| `cancelled` | 已取消（存储值） | 不再展示为履约状态——已取消只体现在「订单进度」 |

- 结算状态（履约单）：收款 × 开票二维组合，如「未收款·已开票」；收款按发货单 `settled` 标记派生，开票按 `invoiceStatus` 二元展示；
- 订单进度（履约单）：分发中 / 履约中 / 结算中 / 已办结 / 已取消（判定优先级：已取消 → 已办结 → 结算中 → 分发中 → 履约中）；
- 销售单订单状态：未处理（未送分发）/ 处理中 / 已办结（全部履约单办结）/ 已取消；另有分发 / 履约 / 结算三个进度聚合。

## 二、履约单字段 —— 单独持有 + 继承销售单

履约单（`parentCode` 指向母单的子单）与母单共用 `ExternalOrder` 接口。按"履约单独有 / 继承销售单"划分：

### 1. 履约单独有字段（拆单时生成/后续履约写入）

| # | 字段 | 说明 |
|---|---|---|
| 1 | `code` | **履约单号** = 母销售单号 + LY01/LY02…（拆单时生成；进入订单默认生成履约单01 = 母单号+LY01） |
| 2 | `parentCode` | 关联母销售单编号 |
| 3 | `createdAt`* | 生成时间（拆单时间；默认履约单01 = 订单录入时间；展示层由 `fulfillmentUnitsOf` 推导） |
| 4 | `items` | **履约单自身的商品明细**（拆单时拆出的商品行；金额 = 履约单金额） |
| 5 | `totalAmount` | **履约单金额**（= 该履约单商品行合计） |
| 6 | `processStatus` | **分发状态**（履约单 5 态：待分发 / 自营待接单 / 分发比单中 / 转派待接单 / 分发已完成） |
| 7 | `path` / `distributeMode` / `partnerId` / `partnerName` / `transferSource` / `transferTime` | 分发路径 / 分发方式 / 履约合作商 / 转出来源与时间 |
| 8 | `partnerStatus` | **履约状态镜像**（合作商链：待接单→已接单→运输中→已妥投→已确收；由 `fulfillment.stage` 自动镜像） |
| 9 | `selfShipments` | **自营发货包裹**（包裹号/仓库/物流公司/单号/商品/状态 shipped→delivered） |
| 10 | `selfPo` | 自营以销定采信息 |
| 11 | `fulfillment` | **履约时间线**（stage 五态 + 来单/接单/发货/妥投/确收 五节点时间） |
| 12 | `history` | 履约单自身的处理轨迹（拆单生成、转出、接单、发货、妥投、确收、对账结算、收款、开票、办结…） |
| 13 | `settleOnTime` | 结算是否按时（纯质量标记，积分奖惩依据） |
| 14 | `settled` | **已收款标记**（结算落库后置位；收款维度） |
| 15 | `settlementStarted` | **已发起对账结算**（订单进度＝结算中） |
| 16 | `closed` | **手工办结**（已收款未开票时手工置已办结） |
| 17 | `invoiceStatus` | 开票维度（二元展示：有值即已开票） |

### 2. 继承销售单的字段（展示在销售单行，履约单不重复展示）

`salesPath` / `sourceChannel` / `platform` / `externalOrderNo` / `customerOrderTime` / `customerOrderNo` / `platformCustomerId` / `platformCustomerName` / `customerName` / `customerType` / `customerRegion` / `receiver` / `receiverPhone` / `receiverAddress` / `remark` / `entryTime` / `operator`

### 3. 关联单据（不在 ExternalOrder 上，按履约单关联查询）

| 单据 | 键 | 说明 |
|---|---|---|
| 采购单 | `purchaseStore.docs[].childOrderCode / childOrderId` | 转派/以销定采生成的直送采购委托单；其 `packages[]` 为发货包裹（FHDXS 发货单号） |
| 采购实价 | 采购单商品行价格 | 淡茶向合作商的实际采购价（= 供货实价） |
