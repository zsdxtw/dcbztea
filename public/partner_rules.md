# 合作商终端 - 设计与业务规则

本文件专门记录**合作商终端**（`/partner` 独立端）的规则，分为**两大类**：

- **第一部分 · 页面设计规则**：对当前已落地设计的总结与沉淀。当前设计为认可基线，后续所有迭代必须保持风格一致
- **第二部分 · 业务逻辑规则**：业务领域规则（待补充）

---

# 第一部分 · 页面设计规则

## 一、设计语言总则

合作商终端是与管理后台完全隔离的轻量门户，设计语言为**「简约大气」**：

1. **大面积留白、细线分隔**：不使用重阴影与色块堆叠，层级靠留白与 1px 细线（`--pk-line` / `--pk-line2`）区分
2. **衬线大标题**：页面标题、统计数字、登录标语统一使用衬线字体 `var(--font-family-serif)`，营造品牌质感
3. **单一翡翠绿点缀**：全端仅一个主色 `#01795D`，不做多模块换色（区别于管理后台的模块色体系）
4. **作用域隔离**：所有样式以 `.partner-shell` / `.pk-login` 为作用域、`pk-` 为类名前缀，定义于独立样式表，不污染主系统
5. **复用主系统基础组件**：表格（Table）、按钮（Button）、详情抽屉（DetailDrawer）等直接复用 `src/components/common`，仅在终端作用域内做轻量覆盖（圆角、聚焦色、字号），不重复造组件

## 二、色彩与字体令牌

定义于 `.partner-shell`（`src/pages/partner/partner.css`）：

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--pk-bg` | `#F5F7F5` | 页面底色（微绿灰） |
| `--pk-surface` | `#FFFFFF` | 卡片 / 面板 / 侧边栏 |
| `--pk-ink` | `#1E2622` | 主文字 |
| `--pk-ink2` | `#57625C` | 次要文字 |
| `--pk-ink3` | `#99A29D` | 辅助文字 / 眉题 / 占位 |
| `--pk-line` | `#E5E9E5` | 主分隔线 / 边框 |
| `--pk-line2` | `#EFF1EE` | 次分隔线（行间细线） |
| `--pk-accent` | `#01795D` | 主色（翡翠绿）：选中、强调、金额、主按钮 |
| `--pk-accent-dark` | `#015F4A` | 主色深（hover / 深字） |
| `--pk-accent-soft` | `#EAF4F0` | 主色浅底（选中底、计数块底） |
| `--pk-radius` | `14px` | 面板统一圆角（输入 9-10px、小元素 6-8px） |

**字体规范**：正文 13-13.5px；描述 12-13px；面板标题 15px semibold；页面标题 26px 衬线；统计数字 33px 衬线 + `tabular-nums`；编号、金额、时间使用等宽 `mono`；眉题 11px + 字距 0.14em。

## 三、整体框架

- **布局**：左侧固定侧边栏 232px（可折叠至 68px）+ 右侧滚动主区 `.pk-main`；页面容器 `.pk-page` 内边距 `34px 44px 48px`
- **侧边栏**（`.pk-side`）：
  - 品牌区：渐变方形 logo（135deg `#028A6B → #01453A`）+ 衬线品牌名「淡茶半盏」+ 小字副题
  - `MENU` 小标签 + 一级菜单（`.pk-nav-item`）：40px 高、9px 圆角、17px 线性图标；hover 浅灰，**激活态 = 主色浅底 + 深绿字 + 左缘 3px 绿竖条**
  - 「设置」带二级子菜单（账号管理/基本信息/仓库信息/资质文件/结算信息）
  - 底部：合作商标识块（公司名 + HZS-编号，上方虚线分隔）→ 用户区（34px 圆形头像缩写 + 姓名 + 角色 + 退出）→ 折叠按钮
- **菜单命名**：短词风格（工作台/订单/报价/抢单大厅/客户/门店/结算/设置），「门店」为一级菜单（页面标题可为「门店信息」）
- **登录态**：`localStorage('partnerAuth')`；未登录访问终端页面自动重定向 `/partner/login`

## 四、页头规范（PageHead）

每页顶部统一 `<PageHead>`（`src/pages/partner/PartnerUI.tsx`）：

- **眉题**：11px 灰、格式固定「合作商终端 · XX」
- **标题**：26px 衬线加粗（h1）
- **描述**：13px、行高 1.7、最宽 760px，用一两句话讲清页面业务含义（面向合作商的口吻）
- **右侧操作区**：可选，放页面级主按钮

## 五、统计带（pk-stats）

- 一体式白色面板 + 细线分隔列（非独立卡片），默认 4 列，3 列用 `.cols-3`
- 每格（`.pk-stat`）：12px 灰标签 → 33px 衬线大数字（单位 13px 灰小字）→ 12px 副注
- **accent 格**：数字用主绿，全带仅 1 格（通常是「待结算金额」类关键指标）
- 数字一律 `tabular-nums`；金额带千分位

## 六、面板与列表行

- **面板**（`.pk-panel`）：白底 + 1px 细边 + 14px 圆角；面板头（`.pk-panel-head`）标题 15px semibold + 前置 3×14px 绿竖线，右侧可放 `.pk-link` 灰色小链接（hover 变绿，如「查看全部 ›」）
- **列表行**（`.pk-rows` / `.pk-row`）：行内边距 13px 22px、行间 1px 次细线、hover `#FAFBFA`；待办行用 38px 绿底圆角计数块（`.pk-num`）打头
- **快捷入口**（`.pk-shortcuts`）：1fr×1fr 网格卡片，hover 边框变绿 + 上浮 1px + 右上箭头变绿
- **双栏网格**：`.pk-grid-32` = 3fr 2fr（如工作台「待办事项 + 快捷入口」）

## 七、工具栏与表格

- **工具栏**（`.pk-toolbar`）：搜索输入（`.filter-input`）+ 下拉筛选（`.filter-select`）+ 右对齐计数（`.pk-count`，如「共 N 单」），可换行
- **表格**：统一装入 `.pk-table-panel`（白底细边 14px 圆角）；表头透明底、12px 灰字带字距；正文 13.5px、行间次细线、末行无线、hover 浅灰
- **单元格强调**：编号用 `cell-mono-emph`、名称用 `cell-emph`、金额等宽 + 主绿加粗、次要信息（日期）用 `cell-muted`
- **状态筛选**：列表上方用 `tab-card-simple` 卡片式状态 Tab（图标 + 名称 +「N 单」计数，激活态绿边 + 浅绿底），不用下拉
- 敏感信息（手机号）脱敏展示（如 `139****2210`）

## 八、药丸标签（Pill）

状态一律用 `<Pill tone>`（22px 高、999px 全圆角、12px 字）：

| 色调 | 底 / 字 | 典型用途 |
|------|---------|----------|
| green | `#E9F4EF` / `#01795D` | 成功、已签收、已定标 |
| blue | `#EDF3FB` / `#1D64B0` | 进行中、已接单、指定分发 |
| amber | `#FBF3E2` / `#9A7A1C` | 待处理、待结算、抢单中 |
| purple | `#F3EFFA` / `#7A5BA6` | 比单、发货中 |
| red | `#FBEDEF` / `#C13A54` | 失败、驳回、超时 |
| gray | `#F0F2F0` / `#67716B` | 中性、已结算、履约中 |

状态→色调映射（订单/报备状态、报备类型、结算状态、客户类型、账号角色）统一从 `PartnerUI.tsx` 导入常量，页面不得自定义状态色。

## 九、表单与按钮

- 输入/选择复用 `.filter-input` / `.filter-select`，作用域覆盖为 36px 高、9px 圆角；聚焦 = 绿边 + 3px 绿光晕
- 按钮复用 `<Button>`：主操作翡翠绿（`btn-primary`，无投影，hover 深绿）、次操作 ghost；行内操作用 `size="sm"`
- 详情抽屉复用主系统 `<DetailDrawer>`：遮罩加深 + 2px 背景模糊、抽屉标题衬线 19px；底部常配「关闭 + 主操作」（`hideFooter` + 自定义 footer）

## 十、登录页（分屏式）

- **左屏**（≥960px 显示）：158deg 翡翠绿渐变（`#01332A → #015F4A → #028A6B`）品牌叙事区——品牌行、小眉题、44px 衬线标语、描述、底部三特性（细线分栏，各含标题 + 一句说明）；可叠加装饰元素
- **右屏**：344px 表单卡居中——眉题 + 28px 衬线标题 + 副说明；44px 输入框、46px 渐变主按钮（字距 0.3em「登 录」）；错误提示浅红条；演示账号放虚线提示框（等宽字体）；底部「返回平台主系统」灰链接
- **注册页**：自带滚动容器（body 全局无滚动）、960px 居中；`pk-reg-panel` 分节白卡 + 3 列栅格（span-2/3）；可增删条目 = 浅绿底卡 + 序号块 + 红色「删除」+ 虚线「+ 添加」；必填红星；提交成功态（64px 圆形图标 + 衬线标题 + 说明）

## 十一、信息设置页（基本信息/仓库/门店/资质/结算）

- `<PartnerProfile>` 按分区（`.pk-section`）承载，分区标题同面板（绿竖线）
- **查看态**：分区展示关键信息 + 页头「申请修改信息」按钮；门店为卡片列表（序号块 + 名称 + 面积 + 状态药丸 + 地址与主营品牌 + 照片缩略）
- **编辑态**：复用注册页表单风格（`pk-reg-*`），可增删条目；修改需提交平台审批后生效（仓库信息除外，免审批直接保存）

## 十二、商机卡片（抢单大厅）

商机场景**用卡片而非表格**：

- 订单卡：白底 14px 圆角细边；左侧 = 编号（等宽加粗）+ 平台药丸 + 状态药丸 + 客户/商品/收货多行信息（13px 灰、行高 1.8）；右侧 = 20px 主绿金额大字 + **实时倒计时**（等宽、临期变橙/红）+ 行动按钮
- 报名/报价表单内嵌在卡片右侧（输入框 + 提交按钮），已报名则显示绿色「已报名 · 报价 ¥X」
- 页面顶部 `tab-card-simple` 切换（可抢订单 / 比单报价 / 客户拜访）

## 十三、交互与反馈规范

1. **倒计时**：每秒刷新（`setInterval` 1s tick），超时自动置灰禁用并触发超时逻辑
2. **操作反馈**：轻量消息条（成功 `#E8F5E9/#01795D`、失败 `#FFEBEE/#C62828`），约 3 秒自动消失，不用全局 toast
3. **空状态**：白底圆角容器内居中灰字，文案给出引导（去哪里、等什么），如「暂无进行中的比单。平台发起比单后可在限期内报名。」
4. **金额格式**：`¥` + 千分位（`toLocaleString`）；积分等纯数字直出
5. **跨页数据**：终端与管理后台共享同一 zustand store（订单流转、报备、积分等），操作即时双向反映
