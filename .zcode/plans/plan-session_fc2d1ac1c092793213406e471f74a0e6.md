# 销售单/履约单状态体系重构

## Context

现状三套状态耦合在一个 `ExternalProcessStatus`（10 态）里：自营执行态（self_accepted/self_shipped/self_delivered）与结算终态（completed）混在分发状态中；履约进度靠 `fulfillment.stage`（5 态）+ `partnerStatus`（7 态）双轨表达；无取消、无开票概念；母单聚合只有 3 维。本次按新口径重构为**分发 / 履约 / 结算 / 开票**四维状态 + 已取消贯穿 + 母单/履约单两级聚合。

## 新状态口径（总表）

**① 分发状态** = `ExternalOrder.processStatus` 收窄为 **7 值**（types/index.ts:1747）：

| 值 | 文案 | 变化 |
|---|---|---|
| `pending` | **待分发** | 改名（原 分发-待处理） |
| `report_match_pending` | 报备-匹配待确认 | 保留 |
| `self_pending` | 自营待接单 | 保留（履约状态一般为待接单） |
| `comparing` | **分发比单中** | 改名（原 比单中） |
| `distribute_pending` | 转派待接单 | 保留（履约状态一般为待接单） |
| `processed` | **分发已完成** | 改名（原 分发-已完成） |
| `cancelled` | **已取消** | 新增 |

删除 4 态：`self_accepted`、`self_shipped`、`self_delivered`、`completed`（履约进度移交履约状态）。规则：**履约状态进入已接单及后续 → processStatus 自动置 `processed`**。

**② 履约状态** = `FulfillmentStage` 重定义为 **6 值**（原 shipped/delivered 改名）：

| 值 | 列表显示 | 说明 |
|---|---|---|
| `pending_accept` | 待接单 | 已分发待主体接单 |
| `accepted` | 已接单 | |
| `shipping` | 运输中 | 原 shipped |
| `transit` | 妥投 | 原 delivered |
| `confirmed` | **已确收** | 管理后台对已妥投订单手工/联机确认 |
| `cancelled` | 已取消 | |

- 载体：`ExternalOrder.fulfillment.stage`（字段已在），合作商链 `partnerStatus` 镜像同步。
- **履约单维度显示**（考虑多发货单，需求⑥）：待接单 / 已接单 / **部分已发货**（部分包裹发货）/ 运输中 / 妥投 / **部分已确收** / 全部已确收 / 已取消；合作商终端「已发货」TAB = 部分已发货+运输中+妥投 桶。
- **发货单（包裹）状态链**：shipped(运输中) → delivered(妥投) → **confirmed(已确收，新增)**。
- `partnerStatus` 收窄：`pending/accepted/shipping/transit/confirmed/rejected/cancelled`（删 `delivered`、`settled`——结算独立成维度）。

**③ 结算状态**（按发货单粒度）：发货单级 `settled` 标记（ShipmentPackage 新增）→ 履约单级 **未结算 / 部分结算 / 已结算**（部分发货单已结算=部分结算）。

**④ 开票状态**（新增字段 `ExternalOrder.invoiceStatus: 'uninvoiced'|'partial'|'invoiced'`）：**未开票 / 部分开票 / 已开票**；入口=详情抽屉「登记开票」。

**⑤ 已取消**：`cancelOrder` action（已确收前可取消）→ 分发状态与履约状态均显示已取消，写处理轨迹。

**⑥ 母销售单聚合**（`familyStatesOf` 重写为 4 维，按履约单聚合）：
- 分发：**未分发**（全部单元待分发）/ **分发中**（无单元分发已完成但存在报备确认/比单/自营待接单/转派待接单）/ 部分已完成 / 全部已完成
- 履约：**未履约**（全部待接单或未履约）/ **履约中**（无单元已确收但存在已接单及后续）/ 部分已完成 / 全部已完成
- 结算：未结算 / **结算中**（存在部分结算）/ 部分已完成 / 全部已完成
- 开票：未开票 / **开票中**（存在部分开票）/ 部分已完成 / 全部已完成
（均附 x/y 数值；单履约单时 1:1 映射显示）

## 实施步骤

### 1. 类型与常量
- `src/types/index.ts`：ExternalProcessStatus 收窄 7 值；FulfillmentStage 改 `pending_accept/accepted/shipping/transit/confirmed/cancelled`；ShipmentPackage.status 加 `'confirmed'`、加 `settled?: boolean`；ExternalOrder 加 `invoiceStatus?:`；PartnerOrderStatus 删 `delivered/settled`。
- `src/data/externalOrders.ts`：EXTERNAL_STATUS_LABELS/COLORS 7 值新文案；`withSeedFulfillment` 重写（按新枚举 + 包裹推 stage）；全部种子迁移（self_accepted→processed+accepted、self_shipped→processed+shipping+包裹、self_delivered→processed+transit、completed→processed+confirmed、partnerStatus delivered→confirmed、settled→confirmed+发货单 settled）；补 1-2 张已取消 + 开票演示单。
- `src/data/partner.ts`：PARTNER_ORDER_STATUS_LABELS/COLORS 更新、种子值迁移；PartnerOrder 加 `settled?: boolean` 派生标记。

### 2. 推导层（列表/详情口径总闸门）
- `src/utils/fulfillment.ts`：6 阶段 LABELS/COLORS（待接单/已接单/运输中/妥投/已确收/已取消）；`stageOfOrder` 兜底重写；新增 `fulfillStateOf(o, pos)` 履约单维度显示（含部分已发货/部分已确收）。
- `src/utils/salesOrderFamily.ts`：删 shipStateOf/旧 settleStateOf；新增 `fulfillStateOf`、`settleStateOf`（按包裹 settled）、`invoiceStateOf`；`familyStatesOf` 输出 4 维聚合（distribute/fulfill/settle/invoice + x/y 计数）；FAMILY_STATE_COLORS 扩充全部新文案色板。
- `src/components/selfop/selfStage.ts`：`selfStageOf` 改由 fulfillment.stage 驱动（pending/accepted/shipping→运输中、delivered→妥投、confirmed→已确收）。

### 3. store 状态机（全部写入点集中在 orderFlowStore）
- `src/stores/orderFlowStore.ts`：
  - `acceptSelfOrder`：→ processed + fulfillment accepted（原 self_accepted）
  - `shipSelfOrder`/`outboundSelf`：包裹写入不变，fulfillment→shipping
  - `deliverSelfShipment`：包裹 delivered，全部妥投→fulfillment transit
  - **新 `confirmReceipt`**（管理后台确收，自营/分发链通用）：已妥投包裹→confirmed；全部确收→fulfillment confirmed
  - `advancePartner`：accepted→processed；shipping/transit→对应 stage；删 delivered/settled 分支
  - **新 `settleOrder(id, {packageNos?, onTime})`**：发货单 settled 标记，全部已发货单结算→履约单已结算，PO settleByChild 联动
  - **新 `cancelOrder(id)`**：已确收前可取消
  - **新 `registerInvoice(id, 'partial'|'full')`**
  - makeSplitChild/resetToPending/transfer 等清空/继承字段补 invoiceStatus、取消态重置
- `src/stores/purchaseStore.ts`：包裹 confirmed/settled 支持 + `confirmByChild`/按单结算 action；seedDocs 映射更新（partnerStatus confirmed→confirmed 包裹、settled→settled 包裹）。

### 4. 管理后台页面
